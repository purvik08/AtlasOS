2. api/server.py – Incorrect uvicorn.run() signature
Lines 15–21

uvicorn.run(
    factory,
    host="127.0.0.1",
    port=8000,
    factory=True,  # ← WRONG: factory is positional, not a kwarg
    loop="asyncio",
)

Problem: You're passing factory as both a positional argument (line 15) and as a keyword argument factory=True (line 18). The correct uvicorn signature is uvicorn.run(app, ...) where if you need a factory, you pass a callable string or object, not a boolean flag.

6. auth/manager.py – JWT token revocation is ephemeral
Lines 159–161

_revoked_jtis: set[str] = set()

Problem: Revoked JTIs are stored in a set that's cleared on server restart. This is documented as a limitation, but tokens revoked before restart can still be used after restart.
